# Per-sugar outputs

Each folder contains the detailed results for one sugar condition.

Typical files:

- `acf.png`
- `corner_plot.png`
- `diagnostics.json`
- `flat_chain.csv`
- `flat_log_probability.csv`
- `likelihood_scan_u.png`
- `log_probability.npy`
- `posterior_predictive_histograms.png`
- `posterior_predictive_simulation.csv`
- `posterior_summary.csv`
- `survival_fit.png`
- `trace_plots.png`
