# Source code

This folder is reserved for reusable Python modules.

Most of the original analysis functions remain in the notebook for readability.

`weibull_adder_sizer.py` implements the alternative three-parameter division
model

```text
H(p | b) = ((p + eta*b) / u)^omega2 - ((eta*b) / u)^omega2
```

where `omega2` is the Weibull shape and `eta` interpolates between adder and
sizer control. The Gamma growth-rate and Beta division-fraction components are
unchanged.

`loglogistic_adder_sizer.py` implements the three-parameter, power-law-tailed
alternative

```text
S(p | b) = (1 + (eta*b/u)^omega2) / (1 + ((p + eta*b)/u)^omega2)
```

which keeps the original total parameter count while adding birth-size
feedback.

`loglogistic_endpoint_residual.py` is the current lineage model.  It uses the
same normalized log-logistic survival law but fits it directly to measured
added sizes reconstructed from consecutive rows of
`data/processed/processed_input_data.csv`:

```text
L_final,n = b_(n+1) / f_(n+1)
p_n       = L_final,n - b_n
epsilon_n = log(L_final,n / b_n) - alpha_n*tau_n
```

Endpoint residuals follow a Student-t location-scale law with four fixed
degrees of freedom, upper-truncated to ensure positive reconstructed division
times.  Inference samples the pivoted scale

```text
b_star = mean transition birth length
p_star = u - eta*b_star
u      = p_star + eta*b_star
```

instead of sampling physical `u` directly.  This unit-Jacobian transformation
preserves the original prior and removes the strong `u`-`eta` posterior
correlation.  Simulated lineages update size with

```text
b_(n+1) = f_(n+1) * (b_n + p_n)
```

and reconstruct time as

```text
tau_n = (log(1 + p_n/b_n) - epsilon_n) / alpha_n.
```

The corresponding runner is
`scripts/run_loglogistic_endpoint_residual.py`.  Its primary finite-lineage ACF
check fixes both the initial size and observed length of every simulated
lineage, preserving the empirical `(b0, lineage length)` pairing exactly.

`alpha_scaled_hill_time_hazard.py` implements the experimental Glu model

```text
h(t | b, alpha) = alpha * omega2 * x(t)^eta / (1 + x(t)^eta)
x(t)            = b * (exp(alpha*t) - 1) / u.
```

It evaluates the cumulative hazard by fixed Gauss-Legendre quadrature and
samples growth time exactly by thinning against the upper growth-time rate
`omega2`.  The same lower-truncated four-degree-of-freedom Student-t endpoint
residual and exact size recursion are retained.  The corresponding runner is
`scripts/run_alpha_scaled_hill_time_hazard.py`.

`latent_setpoint_endpoint_residual.py` adds a stationary AR(1) latent log-scale
to the current endpoint-residual model while replaying measured growth rates
and division factors.  Its two added parameters are the persistence `phi` and
stationary standard deviation `sigma_z`; the lognormal mean correction keeps
the average physical division scale equal to the fitted `u`.  The diagnostic
calibration runner is `scripts/calibrate_latent_setpoint_replay.py`.

`hierarchical_lineage_u_endpoint_residual.py` implements a persistent
log-normal division scale for each lineage.  It marginalizes the lineage
effects with Gauss--Hermite quadrature and exposes their conditional posterior
weights for observation-matched posterior prediction.  The corresponding Glu
runner is `scripts/run_hierarchical_lineage_u.py`.

`hierarchical_lineage_omega2_endpoint_residual.py` implements the complementary
hierarchy with one global `u` and a persistent log-normal `omega2_l` for each
lineage.  Its runner is `scripts/run_hierarchical_lineage_omega2.py`; the direct
Glu model comparison is generated by
`scripts/compare_glu_lineage_hierarchies.py`.
